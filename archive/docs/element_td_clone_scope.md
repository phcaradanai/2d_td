# Element TD Clone Scope

Source of truth: Element TD WC3-style gameplay.

Keep the core loop focused on:

- choose elements
- unlock elemental towers in the shop
- build from the shop
- upgrade each tower family linearly
- clear fixed-path waves
- use gold, lives, and interest

Do not spend time on mechanics outside this scope, including tower relocation, pre-game loadouts, dynamic maze pathing, hero systems, or branch-transform upgrades.

Combination choice belongs in the shop unlock system, not in an upgrade branch menu.
